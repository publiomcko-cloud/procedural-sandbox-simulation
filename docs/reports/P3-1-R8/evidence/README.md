# R8 raw evidence bundle

evidence-bundle.zip contains the preserved R8 attempts (run-001 through run-020) and complete scripts/validate.ps1 captures under validation-001/full-suite and validation-002/full-suite. Failed, interrupted and superseded attempts remain preserved without overwriting raw outputs. The archive's SHA256SUMS.txt hashes every included raw file; the checksum list does not hash itself.

The disposable Godot user-data profiles and profile-probe files are intentionally not published. Local evidence remains preserved. The earlier subset archive was retained locally as an ignored evidence-bundle-pre-run020-*.zip; the published archive contains the complete current raw set. The outer ../SHA256SUMS.txt pins the archive and source/report artifacts.
