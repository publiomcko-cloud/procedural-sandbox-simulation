## PR #15 corrections

- Added negative archive ZIP-size-cap and minimum free-disk-space tests. Each lowers/raises a configured limit only inside `try/finally`, expects the specific guard diagnostic, and verifies the extraction root remains empty.
- Changed adversarial preflight checks to require the expected rejection diagnostic. Stream failure checks require a matching extraction/size diagnostic and verify that the final target was not published. A setup exception cannot count as a passing rejection.

- Added exact size/SHA identity checks. The manifest writer no longer accepts a caller-supplied digest: it checks the pinned **54,457,774-byte** size and pinned SHA-256 before reading entries or writing a success manifest. A synthetic unpinned ZIP test verifies that the writer fails with the size diagnostic and produces no manifest. The manifest no longer claims `native_code_loaded: false`.
- The existing archive manifest and SHA verification record were preserved. No vendor ZIP was downloaded again, and no inventory was regenerated for these corrections.
