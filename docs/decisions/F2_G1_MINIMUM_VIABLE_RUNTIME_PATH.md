## Decision to review

**Use the already provisioned, OFF Hyper-V throwaway VM as the candidate F2 G1 execution environment; do NOT make the protected v2/v3-to-v4/v5 release migration a precondition for the P0.1-F2 compatibility experiment.** This is the minimal *currently identified compliant architecture*, **conditional on environmental gates passing**, not a claim of runtime readiness or the lowest possible implementation cost. The project must keep `BLOCKED_ENVIRONMENT` until the independent ACL, supervisor, storage, network, guest-token, evidence and cleanup conditions are observed.

The P0.1-F2 proof needs an isolated, nonadministrator, offline Windows Godot 4.7.2 project with exact native addon inputs. It does not need to install, migrate or activate the protected C: `F2-G1-Icacls` release service. Production v2 is retained, v3 not independently accepted as installed, and R3 transaction-v4 explicitly provides no v2/v3 live cutover. Attempting protected upgrade would add signature/bootstrap, separate approval authority, crash durability and active-reader cutover questions unrelated to measuring Voxel Tools' behavior.
