## R3 implementation authorization boundary

R2's complete, limited result enables R3 only. R3 is being implemented as an isolated test-only phase: one deterministic joint cavity containing all three frozen residual faces, with a union of dual-graph radius layers L0-L3, at most 64 source triangles and no expansion beyond radius 3. At every level, the candidate patch is removed from the C6 face set and the replacement boundary is derived from actual edge incidence of the remaining C6 mesh. It must be a connected patch with a single oriented boundary cycle; each interface edge must have exactly one removed and one surviving owner with opposite source winding. Invalid levels retain incidence diagnostics and continue. No boundary is inferred from or copied from the rejected R2 L1 cavity boundary.

Field-derived supports come only from the three original frozen residual faces and canonical frozen scalar samples. The support set is deduplicated by exact binary32 position and deterministically ordered. The bounded constrained triangulator receives the entire joint patch and its remaining-mesh-derived boundary, while preserving all frozen topology roots, C6 topology arcs, source-owner boundaries, Candidate D, volume, ROI oracle, controls and strict `cross_squared > 1e-12` cutoff.
