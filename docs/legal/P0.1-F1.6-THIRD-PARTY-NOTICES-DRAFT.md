## Components documented without a drafted license notice

- **SQLite 3.51.0:** The pinned Voxel Tools source identifies version `3.51.0` and SQLite Fossil check-in `fb2c931ae597f8d00a37574ff67aeed3eced`. SQLite states that the deliverable core code and documentation are dedicated to the public domain and specifically distinguishes them from build scripts that do not reach the library. No MIT/BSD notice is invented here. See [pinned version metadata](https://github.com/Zylann/godot_voxel/blob/75d3c6d996ed2331c80edcd8c3ebc947afc0f041/thirdparty/sqlite/VERSION.txt), [pinned amalgamation](https://github.com/Zylann/godot_voxel/blob/75d3c6d996ed2331c80edcd8c3ebc947afc0f041/thirdparty/sqlite/sqlite3.c), and [SQLite copyright statement](https://sqlite.org/copyright.html).
- **FastNoise2:** No object or archive is identified in either historical GDExtension link command. This is a source-path and build-log exclusion only, not direct proof of binary absence. No FastNoise2 notice is included on current evidence.
- **Tracy:** No Tracy source directory exists in the pinned `thirdparty` tree and no Tracy input is identified in either link command. A conditional `SCsub` module-build path references a Tracy path; that reference alone does not show inclusion. No Tracy notice is included on current evidence.
