## Residual operational caveats (not blockers to F1 documentation acceptance)
- Source review and the developer's Windows test log are not independent Windows execution. Passing static GitHub checks do not establish that the PowerShell suite was executed by CI.
- The original release ZIP is a platform-distributed binary package; manifest confirms the project MIT license but no separate third-party notices. Static or transitive inclusion of SQLite, LZ4, meshoptimizer, FastNoiseLite and FastNoise2 is UNKNOWN. A source-tree license is not proof of binary linkage, and a missing notice is not by itself proof of infringement. Before any F2 recommendation, obtain exact binary build manifest/SBOM/linkage evidence or an upstream statement, then reconcile any license/notice obligations. Do not approve shipping/dependency adoption by inference.
- Runtime imports/OS loader deps/ABI, Godot official 4.7.2 GL Compatibility, renderer-specific assets, native signing and async mesh/collision publication revision fencing were NOT tested. First-LOD edit limit remains.
- The safety tool trusts caller-supplied test ZIP in `Extract` mode; the F1 runbook's pinned download identity check remains a required orchestration step, while the manifest writer itself pins the digest. Future automation should not label general ZIP acceptance as proof of v1.7x authenticity without an explicit identity check.
