## GDExtension versus custom-module differences

- The upstream [build/distribution guide](https://github.com/Zylann/godot_voxel/blob/75d3c6d996ed2331c80edcd8c3ebc947afc0f041/doc/source/getting_the_module.md) says the module is a custom Godot engine plus matching export templates; the GDExtension is a native add-on intended to run with official Godot. They aim for similar functionality, but the GDExtension is newer and less tested.
- **FastNoise2 is absent from the GDExtension build.** The custom module build can compile it; upstream source notes FastNoise2 needs C++17 and only benefits x86, falling back to scalar otherwise. This means noise graph parity and performance cannot be assumed. Do not add the separate FastNoise2 extension as an F0/F1 workaround; it would be another dependency requiring owner approval and its own license/artifact inventory.
- The custom module has access to engine internals and a distinct engine/export-template matrix. Its compatibility or feature behavior cannot be used as proof for the GDExtension on the official engine.
- Upstream's platform list and renderer requirements are not a guarantee that every feature works with GL Compatibility. Some GPU generation/normalmap paths require Vulkan/compute; F2 must disable those paths and verify the intended renderer.

## Minimal deterministic analytic fixture proposal

Fixture identifier: `p0.1.f0.analytic_sdf.v1`; coordinates in metres; logical regions are 16 m cubes; test boundary is `x = 0`, with requests on both sides. Use signed density positive inside solid, zero on surface:

```text
plane(p)   = -p.y                         # half-space y <= 0 is solid
hill(p)    = 5 - length(p - (0,-1,0))    # sphere buried in/intersecting plane
base(p)    = max(plane(p), hill(p))       # union of plane and sphere
tunnel(p)  = 1.25 - distance_to_segment(p, (-8,-4,0), (8,-4,0))
density(p) = min(base(p), -tunnel(p))     # subtract continuous cylindrical cave
```

The tunnel crosses `x=0` and spans adjacent logical regions; the union makes an overhang-capable surface and the subtraction creates an enclosed cave/tunnel. Keep the formula and constants versioned. Fixture probes include exact endpoints and centerline, known solid/void points, surface-near points, and a 3D lattice spanning both region sides and their one-sample halo.

- Sample pitch: `0.5 m` for the initial bounded API fixture (not a product-resolution decision).
- Canonical density: evaluate the analytic expression as binary64, then round to nearest-even at `1/4096 m` into signed integer ticks. Record the integer ticks and stable material ID for each lexicographically ordered `(region_i64_xyz, local_sample_xyz)` coordinate. This gives a shared comparison representation; it does not promise cross-architecture bitwise determinism of floating-point `sqrt`.
- Canonical materials: assign stable IDs `terrain.test.base` and `terrain.test.hill`; use a deterministic tie rule (base wins exact union ties). Tunnel void has no material; boundary samples follow the same parent solid result. Later brush tests may add `terrain.test.brush` through a separate fixed command trace.
- Hash canonical domain ticks/IDs and edit trace separately from candidate voxel buffers, mesh bytes, and collider bytes. Compare backend buffers through density tolerance and surface-distance error, not byte equality.
- Instrument mismatch counts, max/mean absolute density error, zero-surface displacement, cave connectivity, border gap/normal defects, deterministic field/edit hash across request orders, and mesh-visible/collision-active revision observations. Set tolerances before any F2 execution; F0 invents no pass threshold.

## F1 procedure (prepared only; not executed)

F1 is a single-artifact acquisition and static inspection. It does not import the archive into Godot or load a native library. Execute only after the owner explicitly approves the exact artifact, license/notice scope, and Windows x64 target described in the handoff.

1. Generate a never-reused test root under the current user's `%TEMP%` using a cryptographically random GUID suffix. Create it without `-Force`; fail if the path already exists. Resolve the canonical full path and verify it is a direct child of the resolved temp root, is not a reparse point, and is outside the repository. Record operator, time, host OS, and approval reference. Do not create a project mirror; that belongs to a separately authorized stage.
2. Download only the fixed release URL above to `artifact\GodotVoxelExtension.zip`; do not use “latest”, Actions artifacts, mirrors, package managers, or helper installers. Keep the ZIP as data: do not double-click it or dispatch it to another application.
3. Compute SHA-256 and compare it to the GitHub asset metadata above. Preserve the result and API metadata. A match is an integrity comparison to GitHub's reported digest, not an independent signature/authenticity proof. If it differs, record the mismatch and stop before parsing/extraction; retain the evidence directory pending review.
4. **Before writing any archive entry to disk**, open the ZIP with the in-box .NET `System.IO.Compression.ZipArchive` API in read-only mode and complete a full central-directory preflight. Reject the whole archive on any unsafe or ambiguous entry. Validate all names, types, collisions, declared sizes, ratios, and total limits below. Do not use `Expand-Archive` or `tar -xf` as the safety check/extractor.
5. Only if every entry passes preflight, extract manually from each `ZipArchiveEntry.Open()` stream into a newly created empty `unpacked\` root. For every output, recompute and verify the canonical destination is beneath the canonical extraction root; create files with `FileMode.CreateNew`; stream in fixed 1 MiB buffers while enforcing both per-file and aggregate actual expanded-byte caps. Create only ordinary directories and regular files. Never restore links, permissions, executable bits, or other metadata. Do not load DLLs, invoke Godot, or run scripts/executables.
6. Record every normalized path, file size, SHA-256 of extracted files, `.gdextension` platform mapping, binary name/size, notices, and rejected/unknown components. Inspect text notices only. Compare the archive inventory with documented Windows x86_64 support and the pinned source dependency/provenance list, including SQLite. If any unexpected or unlicensed component appears, stop before execution.
7. Verify `git status --short` in the assigned worktree still matches the recorded baseline. Keep all F1 artifacts and manifests under the isolated temp root, not the repository. End with an evidence record and whether a separate F2 request is justified; F1 never grants F2 authorization.

### Mandatory archive preflight and resource limits

Treat ZIP path names as hostile even when the GitHub digest matches. Before extraction, require all of the following:

- Archive compressed size at most 100 MiB; at most 20,000 entries; each regular file at most 512 MiB uncompressed; aggregate declared and actual expanded regular-file bytes at most 2 GiB; each entry's expansion ratio at most 200:1 (zero compressed bytes with nonzero output is rejected). Require at least 2.5 GiB free space on the temp volume. These are conservative one-run F1 caps, not estimates of archive contents. If the official archive exceeds a cap, stop and request a revised reviewed plan; do not silently raise limits.
- Reject NULs, empty names, absolute/rooted paths, leading slash, UNC paths, drive prefixes, any backslash, colon/alternate data stream syntax, `.` or `..` components, empty interior components, trailing spaces/dots, and Windows reserved device-name components. Accept only normalized relative ZIP paths using `/`; permit a single final `/` only to mark a directory.
- Reject symbolic links, reparse points, devices, sockets, FIFOs, and any non-regular/non-directory type. Inspect ZIP external attributes (Unix mode and DOS attributes); directory markers and file type must agree with the path form. Never follow or recreate a link.
- Normalize Unicode names to NFC and detect duplicate paths and case-insensitive collisions using Windows ordinal case-insensitive comparison. Reject file/directory name conflicts and prefix conflicts (for example, a regular file `a` alongside `a/b`). Reject duplicate explicit directory entries too.
- Validate every final path with `Path.GetFullPath` and a separator-terminated canonical extraction root using ordinal case-insensitive containment. Reject any result equal to the root or outside it. Check the extraction root and every parent for reparse points immediately before creating output.
- During extraction, enforce actual byte limits while streaming (do not trust only central-directory size fields), use `CreateNew` so an existing path cannot be overwritten, and abort on decompression/read errors or declared/actual size mismatch. Keep memory bounded to one 1 MiB buffer per copy. No shelling out to an archive utility is needed.

Any preflight failure means **zero extraction**. Preserve the manifest and archive for review in the isolated root; do not try a different extractor or partial extraction.
